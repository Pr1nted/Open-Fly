# The itch.io page

```
cover.png          630x500, the project cover (upload cover@2x.png: itch downsamples)
cover@2x.png       1260x1000
thumbnail.png      1280x720, the first screenshot, and the social card
banner.png         1600x500, Edit theme -> Banner
favicon/           the browser-tab icon: upload favicon-128.png (see 4. Media)
description.html   paste into the description (switch the editor to HTML first)
theme.css          Edit theme -> the CSS box
README.md          this
```

The art is a still from the same room the page renders (`scene/fly_at_computer.py
--wall-map`, frame 1 and frame 300 of the 1914 Sweden game), with the console
titles laid over it. The titles use Press Start 2P and JetBrains Mono, both OFL.
When the room changes, re-render and re-compose; nothing keeps them in step.

**Keep the project in Draft until the green light.** Everything below can be set
up in advance. Publishing is one switch.

## 1. Create the project

**Dashboard -> Create new project.**

| Field | Value |
|---|---|
| Title | Open Fly |
| Project URL | `open-fly`, so the butler target is `pr1nted/open-fly:web` |
| Short description | A simulated fruit-fly brain plays Open Doctrines, live in your browser. |
| Classification | Games |
| Kind of project | HTML |
| Release status | Released. It does what it says. "Prototype" undersells a finished page. |
| Pricing | **No payments**, and no donations. The connectome is CC BY-NC 4.0, so nothing on this page may ask for money (see `web/data/LICENSE.txt`). |
| Genre | Simulation |
| Tags | `simulation`, `grand-strategy`, `neuroscience`, `artificial-life`, `zero-player`, `science`, `experimental`, `strategy`, `psychological-horror`, `browser` (the horror tag is the description's joke; itch allows 10 tags, so it replaced `open-source` while the repository is private) |
| AI generation disclosure | No. Nothing on the page is generated by a generative model. The brain is a spiking simulation. |
| Community | Comments on. The science questions are the best part. |
| Visibility | **Draft** until launch |

**Why Games and not Other:** itch hides Other from browse and search. It is a
zero-player game, which is a real category (Conway's Life is filed there), and
the tags say plainly what it is.

## 2. Embed options

| Option | Value | Why |
|---|---|---|
| Embed | Embed in page | |
| Viewport | **1280 x 720** | measured: the setup panel, stats panel and status bar all fit with room to spare. At 960 x 600 the setup panel runs into the status bar, so nothing smaller than about 1100 x 700 |
| Fullscreen button | on | the room is worth seeing large |
| Automatically start on page load | **off** | 65 MB and a busy CPU are not something to start on a visit |
| Mobile friendly | off | 138,639 neurons in JavaScript is a desktop job |
| Scrollbars | off | |
| SharedArrayBuffer support | off | not used, and it would break the third-party iframes itch needs |

## 3. Theme

In **Edit theme**, set the pickers first (they are what shows before the CSS
loads), then paste `theme.css` into the CSS box:

| Picker | Value |
|---|---|
| BG | `#030806` |
| BG2 | `#06120D` |
| Text | `#B8F5D2` |
| Link | `#4DFF9B` |
| Button | `#4DFF9B` |
| Banner | `banner.png` |
| Screenshots | Right column |

Then check the page at phone width. `theme.css` turns its motion off under 700px
and under `prefers-reduced-motion`.

## 4. Media

- Cover: `cover@2x.png`.
- Favicon: **Edit game -> Metadata -> Promo images -> Favicon**, `favicon/favicon-128.png`.
  Press **Save** before leaving: an unsaved favicon shows on the edit page and then
  disappears. The icon is a pixel fly on the console void, with the gold top edge
  from the cover. It is square and opaque, so itch's transparency bugs cannot touch it.
  `favicon/make_favicon.py` redraws every size from one 16x16 grid.
- Screenshots: `thumbnail.png` first, then three frames of the live page, taken
  when the fly is at war (the orders panel is busiest). The first screenshot is
  what Discord, Bluesky and X show when someone pastes the link.
- Trailer: a YouTube link to the 30-second clip, once it exists (see
  `docs/launch.md`).

## 6. Builds: butler, from CI

`.github/workflows/follow-open-doctrines.yml` pushes the staged site (`dist/`)
to `pr1nted/open-fly:web` with `--userversion` set to the Open Doctrines tag it
was built from. The upload is about 70 MB in fewer than 30 files, far inside
itch's HTML limits (1 GB, 1000 files). After the first push, tick **This file
will be played in the browser** on the upload once. Later pushes keep it.

butler uploads builds and nothing else. The cover, theme, CSS and description are
dashboard-only.

## 7. Devlogs

itch has no devlog API. The workflow writes the post to `release/itch-devlog.md`
and prints it in the run summary. Paste it into **Devlog -> New post**, type
*Update*, with `thumbnail.png` as the post image. The same text goes up on its
own at `open-fly.pages.dev/devlog/`, with an RSS feed, and to Discord if the
webhook is set, so the itch post is the only manual step.
